ADLC modes can overlap. Generate and Validate work together. Observe sends new questions to Intent. This links Agent work to human decisions and results that people can check.

01

Intent

Human + Agent

Turn a question into a hypothesis with a clear target and guardrails.

hypothesis · target · guardrails
02

Generate

Agent executes

Create the spec, plan, code, and documents within the confirmed scope.

spec · plan · implementation
03

Validate

Agent verifies

Work with Generate. Check tests, edge cases, and evidence for the revision.

tests · review · evidence
04

Govern

Human decides

Review the Intent, risks, and evidence. A human chooses what happens next.

decision · resolution
05

Deploy

Agent prepares

Release the approved revision to its target. Check its health and recovery steps.

release · health check · rollback
06

Observe

Signal + judgment

Study real behavior apart from test data. Use the result to ask a new question.

signals · guardrails · observation
Observe → Govern gives the decision to a human: Resolved, Iterate, or Stop. Iterate sends a signal to the next Intent.

Intent 1 · Finish one round

  • Build a 1–100 number game with seven guesses.
  • Generate and Validate the game together.
  • A human approves the revision before a test release.
  • Observe completion and the effort needed to start again.

Intent 2 · Choose a second round

  • The first signal makes the question about longer play more clear.
  • Add a Play again button and keep the main game rules.
  • Measure replay rate with a completion guardrail.
  • A target can pass while a guardrail fails. A human must still Govern.
