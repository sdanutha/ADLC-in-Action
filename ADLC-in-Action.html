Agent ลงมือ
มนุษย์กำกับ

ADLC เป็นวงจรของโหมดที่ทำงานซ้อนกัน โดยเฉพาะ Generate ↔ Validate และ Observe → Intent เพื่อเชื่อมการลงมือของ Agent กับการตัดสินใจและผลลัพธ์ที่มนุษย์ตรวจสอบได้

01

Intent

Human + Agent

เปลี่ยนโจทย์เป็น hypothesis ที่วัดได้ พร้อม target และ guardrail

hypothesis · target · guardrails
02

Generate

Agent executes

สร้าง spec, plan, code และเอกสารภายใต้ขอบเขตที่มนุษย์ยืนยัน

spec · plan · implementation
03

Validate

Agent verifies

วนร่วมกับ Generate ผ่าน tests, edge cases และหลักฐานที่ผูกกับ revision

tests · review · evidence
04

Govern

Human decides

ประเมินความสอดคล้องกับ Intent ความเสี่ยง และหลักฐาน ก่อนเลือกทางไปต่อ

decision · resolution
05

Deploy

Agent prepares

นำ revision ที่อนุมัติไปยัง target ที่กำหนด พร้อมตรวจสุขภาพและวิธีกู้คืน

release · health check · rollback
06

Observe

Signal + judgment

วิเคราะห์พฤติกรรมจริง แยกจาก test data แล้วใช้ผลตั้งคำถามรอบใหม่

signals · guardrails · observation
Observe → Govern ให้มนุษย์เลือก Resolved, Iterate หรือ Stop; Iterate ส่ง signal ไปสร้าง Intent ถัดไป

Intent 1 · เล่นให้จบหนึ่งรอบ

  • สร้างเกมทายเลข 1–100 ภายใน 7 ครั้ง
  • Generate และ Validate เกมไปพร้อมกัน
  • มนุษย์อนุมัติ revision ก่อนนำไปทดลอง
  • สังเกต completion และ friction ของการเริ่มรอบใหม่

Intent 2 · อยากเริ่มรอบสอง

  • Signal จากรอบแรกเปลี่ยนคำถาม “เล่นนานขึ้น” ให้ชัดขึ้น
  • เพิ่มปุ่มเล่นอีกครั้งโดยคงกติกาหลัก
  • วัด replay rate พร้อม completion guardrail
  • เป้าหมายผ่านแต่ guardrail พังได้ มนุษย์จึงยังต้อง Govern
